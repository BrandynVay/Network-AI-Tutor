5. Firewalls in depth (stateful vs stateless, ACLs, NGFW, zones/DMZ)
6. Physical and logical security controls (locks, badge access, cameras
   vs VLAN segmentation, port security, NAC)
7. VPNs and remote access security (site-to-site vs client, IPsec vs SSL
   VPN)
