# Domain 5 — Network Troubleshooting (24% of N10-009)

Standing reference chapter — see `CLAUDE.md` for how this file is
maintained. **Not written yet.** Planned contents:

1. CompTIA's network troubleshooting methodology (the ordered steps —
   identify the problem, establish a theory, test the theory, establish
   a plan of action, implement, verify, document — and why the exam cares
   about the *order*)
2. Common command-line tools (ping, traceroute/tracert, nslookup/dig,
   ipconfig/ifconfig, netstat, arp, tcpdump/Wireshark at a conceptual
   level) — what each one actually tells you and when to reach for it
3. Cable/physical layer troubleshooting (signal loss, crosstalk, wrong
   cable category, bad connector, TX/RX reversed)
4. Common wired/wireless issues (switching loops, duplicate IPs, DHCP
   exhaustion, wrong VLAN, channel overlap/interference, weak signal)
5. Reading link lights and port status indicators
6. Working through symptom-based scenario questions methodically instead
   of pattern-matching to a memorized answer
